# Lab-Exercise-6

AIM:
To generate UX solution ideas and develop user stories, scenarios, user flows, and information architecture for an on-demand ride-hailing and auto/cab booking application.

ALGORITHM:

1. Identify the UX problems related to daily urban ride-hailing and auto/cab booking.

2. Use the Crazy 8s method to generate multiple rapid solution ideas.

3. Create user stories addressing common commuter pain points (cancellations, pricing, safety).

4. Develop a realistic scenario for booking an auto/cab during peak campus/office rush hours.

5. Map the end-to-end user flow from app launch to drop-off and payment completion.

6. Identify critical decision diamonds and alternate system loops (driver unavailability, retry paths).

7. Create the information architecture using closed card sorting.

8. Group core features into structured functional categories (Ride Booking, Active Trip, Safety Shield, Payments & History, Account).

9. Build the hierarchical site map for the SwiftRide mobility platform.

10. Verify that the user stories, scenarios, user flow, and IA address friction points in urban transit.

OUTPUT:

[ex 6  uiux.pdf](https://github.com/user-attachments/files/31842337/ex.6.uiux.pdf)

RESULT:
A complete UX solution for the SwiftRide Mobility App was developed, including Crazy 8s ideation, commuter user stories, a ride-booking scenario, an end-to-end task flow with alternate loops, and an information architecture site map.
